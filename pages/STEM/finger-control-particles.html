Finger-Controlled Particle Simulation

A Python STEM project that uses MediaPipe hand recognition to control a live particle world. Students can see computer vision, gesture logic, physics, and creative coding working together in real time.

Project Overview

This project turns a webcam into a controller. MediaPipe reads the hand as 21 landmark points, the program counts raised fingers, and a particle simulation responds with different visual behaviors. The result is a playful bridge between artificial intelligence, geometry, and interactive design.

Gesture Controls

The hand controls are designed like a visual language: each gesture changes the behavior of the particles.

Gesture Particle Effect
FistPack the particles back into a mound.
One fingerCondense the particles into a ball.
Middle fingerForm an angry face.
Two fingersArrange the particles into a V shape.
Three fingersCreate a swirling sandstorm effect.
Four fingersChange the particle color palette.
Five fingers moving upwardDisperse the particles outward.
Two handsScoop particles upward while some leak through the gap.

What Students Learn

Computer Vision

How a webcam image becomes hand landmarks that software can measure.

Coordinate Geometry

How x-y positions, distance, direction, and velocity control movement on screen.

Physics Thinking

How gravity, damping, force, collision, and friction create natural particle motion.

Program Design

How classes, functions, constants, and gesture states organize a growing project.

Run the Project

Open Terminal in the website folder and run the Python program with Python 3.12.

python3.12 python_projects/hand_sand_simulation/sand_simulation.py
The main window shows the particle simulation. The smaller preview window shows the 21-point MediaPipe hand graph used for recognition and debugging.
