How This Works

Computer Vision

The webcam creates video frames. MediaPipe analyzes each frame and estimates 21 hand landmark positions.

Coordinates

Normalized coordinates use x = 0 on the left, x = 1 on the right, y = 0 at the top, and y = 1 at the bottom.

Live fingertip: --

Vectors

The app subtracts the index base from the fingertip: dx = tipX - baseX, dy = tipY - baseY.

That vector is normalized so it keeps direction without growing too large.

Speed

The wand compares this frame with the previous frame: speed = distance / time.

Live speed: 0

Gesture Recognition

The browser remembers recent wand-tip positions and compares the shape to forgiving circle and Z patterns.

Collision Detection

The invisible wand is a ray. A target is hit when the target center is close enough to that ray and in front of the fingertip.
