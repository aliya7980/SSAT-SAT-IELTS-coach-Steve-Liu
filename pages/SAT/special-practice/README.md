# SAT Special Section Practice — Details

34 untimed questions from the user-supplied Details.pdf (2025 collection), in PDF order. Each question has its own question.html?q=N address. Passages and choices reflow as readable text, with full-text clickable radio choices. Original PDF formatting remains available in an expandable source section; select a crop to enlarge it. The source images are authoritative. Source crops use lossless WebP compression. The source PDFs are unchanged and are not published.

## Student flow
Enter name, answer questions, optionally mark for review, then open My response sheet. Choices persist in this browser under a separate Details storage key. Download the response JSON and give it to the teacher. Restore a response file on the Details home page when changing browsers. The student grade page opens the teacher-returned report and displays score, percentage, answered/unanswered totals, submission time, and grading time. No timer or official SAT scaled score.

## Private teacher grading
The local tool lives at .sat-private/details-teacher-grader.html. Open it directly in a browser, load a student response JSON, review the private key and choices, and download the student grade report. Return that report to the student. The supplied detailskeys.pdf was transcribed and visually checked for questions 1–34.

The entire .sat-private directory is excluded by .gitignore. Never copy the teacher grader, key JSON, or source key PDF into public pages or assets. Correct answers are not included in any public practice file or exported student report. This is a manual teacher-return workflow, not automatic online grading; GitHub Pages has no private grading server. Grade report files are ordinary local feedback documents, not cryptographically authenticated records.

## Source verification
source-manifest.json records the source PDF SHA-256 and 68 source-image crops, with original PDF page index/number and coordinates measured on 3840 × 2160 source images. No charts or tables were redrawn. All passage and four-choice crops were inspected in contact sheets. No answer analyses were published.
