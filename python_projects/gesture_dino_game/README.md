# Gesture Dino Runner

A simple webcam-controlled dinosaur runner inspired by the classic browser dinosaur game.

Controls:

- Hold up one finger and move it upward: jump.
- Hold up one finger and move it downward: crouch.
- Keyboard fallback: `Space` jumps, `Down Arrow` crouches, `R` restarts, `Esc` quits.

Run:

```bash
python3.12 gesture_dino_game.py
```

If macOS asks for camera permission, allow Terminal or VS Code to use the camera.
