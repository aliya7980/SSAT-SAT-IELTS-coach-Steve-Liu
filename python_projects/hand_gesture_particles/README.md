# Hand Gesture Particles

This Python project uses your webcam and MediaPipe hand tracking to control an atom structure.

- One finger: spin the electrons.
- Two fingers or pinch: draw the electron orbits closer.
- Three fingers: pick out one electron.
- Four fingers: swap to a different atom.
- Five fingers: grab and move the atom.
- Press `q` to quit.
